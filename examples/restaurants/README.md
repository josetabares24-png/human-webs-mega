# Ejemplos de restaurantes — Referencias de código

Patrones de botones, CTAs, heroes y elementos de interfaz tomados de las webs de restaurantes más populares y visitadas del mundo (McDonald’s, Domino’s, Chipotle, Shake Shack, Sweetgreen, Pizza Hut, Starbucks y fine-dining de alto tráfico).

**Uso**: copia, adapta y combina. El objetivo es velocidad + sensación humana, no copiar pixel a pixel.

## Sitios de referencia principales (tráfico global)

| Sitio | Tipo | Por qué mirarlo |
|-------|------|-------------------|
| mcdonalds.com | QSR global | Claridad extrema, CTA de pedido dominante |
| dominos.com | Pizza | Pizza Tracker + orden rápida |
| chipotle.com | Fast-casual | Flujo de pedido optimizado |
| shake-shack.com | Fast-casual | CTA "Order" siempre visible |
| sweetgreen.com | Fast-casual | Orden como infraestructura |
| pizzahut.com | Pizza | Orden + localización |
| starbucks.com | Café | Mobile-first, recompensas |
| opentable.com | Reservas | Flujo de reserva limpio |
| Commander's Palace, Carbone, etc. | Fine dining | Hero + "Reserve" claro |

## Archivos en esta carpeta

- `button-patterns.md` — botones y CTAs reutilizables (HTML + CSS)
- `hero-patterns.md` — heroes con foto + CTA
- `sticky-cta.md` — barras fijas inferiores (muy usadas en restaurantes)
- `popular-chains-notes.md` — notas rápidas de cada cadena

## Cómo usar

1. Elige el patrón que encaje con el tipo de restaurante (QSR, casual, fine dining).
2. Copia el HTML/CSS.
3. Adapta colores, tipografía y copy al negocio concreto.
4. Pasa el checklist anti-IA antes de entregar.
