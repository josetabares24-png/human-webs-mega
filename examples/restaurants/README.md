# Ejemplos de restaurantes — Referencias de código

Patrones de botones, CTAs, heroes y elementos de interfaz tomados de las webs de restaurantes más populares y visitadas del mundo (McDonald’s, Domino’s, Chipotle, Shake Shack, Sweetgreen, Pizza Hut, Starbucks y fine-dining de alto tráfico).

**Uso**: copia, adapta y combina. El objetivo es velocidad + sensación humana, no copiar pixel a pixel.

## Ejemplo funcional

- **[demo-la-mesa.html](demo-la-mesa.html)** — Landing completa y funcional de "La Mesa". Abre el archivo en el navegador (o usa GitHub Pages / raw). Incluye hero, menú HTML, sticky CTA móvil, botones, copy humano y click-to-call.

## Cómo usar

1. Abre `demo-la-mesa.html` para ver un ejemplo real funcionando.
2. Lee `premium-and-famous-patterns.md` para entender diferencias entre casual y premium.
3. Elige el patrón que encaje con el tipo de restaurante (QSR, casual, fine dining).
4. Copia el HTML/CSS.
5. Adapta colores, tipografía y copy al negocio concreto.
6. Aplica los patrones móviles (la mayoría de visitas son en móvil).
7. Pasa el checklist anti-IA antes de entregar.
