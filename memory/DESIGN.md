# Diseño de webs originales, no de plantillas repetidas

**Regla:** cada web merece una dirección de arte propia. El problema no es que un color o un botón «parezca IA», sino repetirlos sin relación con el negocio.

## Síntoma que debemos evitar
Feedback explícito del usuario (2026-10-30): **fondo terracota recurrente**. Otras combinaciones fáciles (crema + serif elegante + hero centrado + tres tarjetas + CTA redondeado) pueden ser igualmente repetitivas. No utilizar estos patrones como plantilla inicial. No prohibirlos si identidad y función los respaldan.

## Proceso obligatorio (web nueva o rediseño con libertad visual)
1. **Reconocer marca:** sector, cliente, público, precio, personalidad, ubicación, contenido real, propósito y materiales licenciados. Respetar identidad preexistente; no imponer un rediseño arbitrario.
2. **Investigar:** seguir [ART-DIRECTION](ART-DIRECTION.md); comparar webs reales pertinentes y otras de sectores contrastantes. Una galería es un punto de descubrimiento, no prueba de que la web fue inspeccionada.
3. **Tres direcciones:** formular composiciones diferentes con variación en jerarquía, estructura, tipografía, imagen, paleta, navegación y acción principal. No son el mismo CSS con tres fondos.
4. **Elegir y justificar:** seleccionar la opción con mejor ajuste a contenido, identidad, conversión, accesibilidad, recursos y coste; documentar por qué se descartaron las otras. No pedir al usuario elegir si el encargo permite autonomía.
5. **Aplicar al sitio completo:** home, internas, menús, footer, estados vacíos, formularios, responsive. Screenshots en 390px y 1280px. Corregir inconsistencias.
6. **Aprender:** si el usuario rechaza «demasiado IA», registrar qué componentes concretos fallaron, no solo la etiqueta subjetiva.

## Paleta: sin receta universal
- No fijar `#b86e50`, `#c47459`, arcilla, terracota, arena, crema ni variantes como valores iniciales globales. Tampoco reemplazar el terracota por **otro** color constante.
- Derivar fondos y acentos de logotipo autorizado, espacio real, producto, fotografía, arquitectura, identidad o referencias contrastadas.
- Explorar **sistemas** distintos: contraste tipográfico sobre blanco puro, fotografía con fondo carbón, color corporativo dominante, interfaces funcionales claras, editoriales de papel, composiciones cromáticas intensas, etc. Son posibilidades, **no presets obligatorios**.
- Un sitio de marca terracota puede conservar ese color; registrar la evidencia de identidad y resolver composición única, no replicar un template.

## Componentes y estructura
- Definir tokens de contraste, tamaño, espaciado, radios y estados; fuentes legales con fallback coherente. No mezclar estilos de negocios distintos a ciegas.
- Estructura en función del contenido: menú HTML para restaurante cuando convenga, agenda para servicios, catálogo para producto, datos editoriales para un medio. No crear tarjetas solo para llenar espacio.
- CTAs con acciones reales; navegación útil, lectura y operación móvil. Animación solo cuando ayuda y contempla accesibilidad.
- Un copy específico no salva un layout idéntico; revisar ambas dimensiones.

## Evidencia
En el proyecto de destino guarda una ficha breve con tres direcciones y selección siguiendo [DESIGN-DIRECTION-TEMPLATE](DESIGN-DIRECTION-TEMPLATE.md). Anota URL, fecha, viewport y límites de las referencias efectivamente inspeccionadas. No afirmar que «pasó el filtro anti-IA» sin revisión comparativa.
