# Guía de diseño con identidad real

**La estética anti-IA no es un estilo.** Es evitar soluciones previsibles o descontextualizadas sin sacrificar claridad.

## Antes de diseñar
- Identifica negocio, carácter, rango de precio, tipo de público, tono, objetivo de conversión y assets disponibles.
- Define una frase de identidad específica y una dirección visual con una razón (no «elegante» a secas).
- Consulta `examples/restaurants/biblioteca.md` para restaurantes y `examples/mobile-ux-patterns.md` para móvil; sus observaciones no se extrapolan a todos los sectores.
- Distingue fuente verificada y adaptación. Marca como pendiente toda tipografía no licenciada, foto no autorizada y medida no observada.

## Sistema coherente
- Define tokens: fondo, texto, superficies, bordes, acentos, tipografías con licencias, tamaños, ritmo vertical, radios, sombras.
- Elige un criterio compositivo claro: editorial, utilitario, cartel, minimalista, expresivo, etc., sin mezclar aleatoriamente.
- Diseña jerarquía por necesidad: qué entiende la persona en 5 s, acción principal, evidencia real, ubicación y navegación.
- Adapta **todas** las plantillas y estados, no solo el primer scroll.
- CTA debe describir una acción real; evitar botones que no llevan a ningún lugar.
- La web puede usar cards, serif, sans, gradientes o píldoras cuando se justifiquen; no son errores por sí mismos.

## Comprobación estética
Preguntas: ¿podría este título servir para 100 negocios? ¿Hay afirmaciones sin soporte? ¿La referencia visual se nota copiada? ¿Tiene una narrativa de diseño consistente? ¿Se entiende desde móvil? ¿Las fotos son reales? ¿El botón hace lo que promete?

Distingue revisión humana (criterio) de test automático (evidencia), y registra correcciones frecuentes en `memory/ERRORS.md`.
