## Qué debe resolver una web gastronómica
- Platos, carta con información real y precios confirmados (si se ofrecen).
- Fotografías autorizadas de comida y local.
- Ubicación precisa y mapa útil para un negocio físico.
- Horarios y contacto coherentes entre rutas.
- Reserva si está realmente integrada, o enlace directo a canal externo verificado.
- Tono y diseño adecuados al concepto: una cafetería lúdica no equivale a un restaurante de degustación.

**Nunca:** transferir automáticamente esta estética o una carta gastronómica a webs de limpieza, reformas, asesorías o servicios de salud. [Volver a sectores](../README.md).
