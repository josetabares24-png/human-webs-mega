# Belleza, barberías y tratamientos

Barberías, peluquerías, manicura, estética no médica, wellness de atención presencial.

**Funciones que importan:** Lista legible de tratamientos con precios/duración confirmados; trabajos y profesionales reales; ubicación, mapa, reserva y política de cambios.

**Riesgo de copiar sin contexto:** No fingir citas libres o reservas confirmadas. No inventar credenciales ni fotos de antes/después.

## Referencias investigadas (pendientes de aprobación)

- **[Ruffians](ruffians.md)** — barberías con sedes físicas. En salón/barbería, dar protagonismo al trabajo real, profesionales, servicios, duración/precio si están confirmados, mapa, horario y reserva por sede.
- **[Treatwell](treatwell.md)** — marketplace de reservas de belleza. Para una clínica estética o peluquería, listar tratamientos, duración/precios reales, profesionales y paso de cita verificable; responder dudas frecuentes antes del contacto.

**Análisis ampliado:** cada caso incluye evidencia visual, lectura de tipografía/fondo/foto/CTA, propuesta original para una pyme y comprobaciones pendientes. [Comparativa de diez](../COMPARATIVA-VISUAL.md).

Las fichas derivan de páginas web públicas consultadas el 30/10/2026. **No hay capturas nuevas de móvil ni inspección de CSS**; las conclusiones visuales no medidas se marcan como interpretaciones.
