# Estándar de investigación para una web de servicios

La ficha útil para Codex no es una lista de colores. Debe separar **hechos**, **observaciones de imágenes**, **adaptaciones hipotéticas** y **preferencias aprobadas**.

1. Fuente original exacta, fecha y tipo de negocio (proveedor, varias sedes o marketplace).
2. Recorrido comercial visto en la web oficial: qué problema resuelve, información, CTA y destino.
3. Evidencia visual atribuida, con fecha de captura si se conoce y límites si es un archivo.
4. Fondo, color, tipografía, fotografía, hero, estructura y navegación. Anotar **no medido** si no se verificó.
5. Idea distintiva transferible, conectada con un problema real del cliente.
6. Boceto original de implementación para **una pyme**, con servicios, equipo y recursos autorizados.
7. Copy humano marcado como hipotético; jamás inventar valoraciones, premios, precios o direcciones.
8. Riesgos de propiedad intelectual, privacidad, expectativas, agenda y cobertura.
9. Criterios de prueba móvil, accesibilidad, carga de imágenes y acciones/recepción.
10. Estado de aprobación del usuario. **Investigar no es aprobar.**

**Método aplicado a las diez fichas (30/10/2026):** consulta de sitios oficiales y páginas visuales atribuidas; no hay nuevas capturas propias del navegador ni medidas de CSS. La biblioteca debe mejorarse después con capturas autorizadas actuales y feedback concreto, no rellenar lo desconocido con precisión falsa.
