# Servicios profesionales y creativos

Despachos, asesorías, consultoras, estudios de diseño, fotografía y agencias.

**Funciones que importan:** Especializaciones, personas reales, casos documentados, metodología y contacto con expectativas claras.

**Riesgo de copiar sin contexto:** No atribuirse clientes o premios ajenos, no prometer resultados jurídicos/económicos. Portafolio inventado = rechazo.

## Referencias investigadas (pendientes de aprobación)

- **[PLMJ](plmj.md)** — despacho de abogados. Para despachos o asesorías: explicar especializaciones, perfiles reales, experiencia comprobable, ámbito geográfico y contacto sin promesas de resultados.
- **[Koto](koto.md)** — estudio/agencia creativa. Para fotógrafos, diseñadores, arquitectos y consultorías, priorizar 3-6 proyectos reales con contexto, trabajo realizado, resultado verificable y contacto claro.

**Análisis ampliado:** cada caso incluye evidencia visual, lectura de tipografía/fondo/foto/CTA, propuesta original para una pyme y comprobaciones pendientes. [Comparativa de diez](../COMPARATIVA-VISUAL.md).

Las fichas derivan de páginas web públicas consultadas el 30/10/2026. **No hay capturas nuevas de móvil ni inspección de CSS**; las conclusiones visuales no medidas se marcan como interpretaciones.
