## Hechos observados en la web
Presenta trabajos seleccionados como prueba del servicio, separa estrategia, identidad, digital y campañas y facilita contactos de oficinas. El portafolio explica problemas y soluciones por proyecto.

## Lectura visual/estructural
Narrativa visual impulsada por casos y marcas creadas, no por una sucesión de testimonios genéricos. El estudio de desarrollo describe un sitio de portafolio y captación; no se han medido layouts actuales.

## Principio reutilizable para Human Webs
Para fotógrafos, diseñadores, arquitectos y consultorías, priorizar 3-6 proyectos reales con contexto, trabajo realizado, resultado verificable y contacto claro.

## Qué no copiar ni inferir
No reutilizar logotipos/campañas de Koto, clientes reconocibles ni cifras de impacto como propios. No copiar efectos pesados sin rendimiento.

## Ejemplo de estructura útil (hipótesis; no aprobado)
**CTA y recorrido:** Ver casos reales → explicar proyecto → solicitar contacto.

## Validaciones antes de implementar
Cada caso debe existir, mostrar propiedad/licencia, y el CTA debe llegar a un canal verdadero sin formulario ficticio.

**Prohibido:** usar sus imágenes, testimonios, logos, copy o precios para clientes sin licencia y verificación. La ficha es investigación, NO una plantilla ni una auditoría visual completa.

## Auditoría visual ampliada (investigación, no aprobación)

**Idea central del caso:** Portafolio negro y tipográfico con casos que venden sin discurso vacío.  
**Evidencia consultada:** Oficial actual + archivo de captura 2025 publicado por Lapa Ninja.  
**Confianza en la observación:** media para captura de 2025; alta para tipos de servicios/casos actuales; baja para datos visuales técnicos..

### Evidencia visual y límites
- [Material visual o página de estudio atribuido](https://www.lapa.ninja/post/koto/). Se consulta como **referencia**, no como imagen disponible para reutilizar en una web comercial.
- Sitios oficiales y recorridos verificados: [fuente](https://koto.com/) · [fuente](https://koto.com/work) · [fuente](https://koto.com/services) · [fuente](https://madebyon.com/case-studies/koto-studio/).
- **Sin captura propia nueva de móvil/escritorio, sin inspección de CSS computado, sin tipografías licenciadas extraídas, sin prueba de conversión.** La imagen puede reflejar una versión anterior. No afirmar lo contrario.

### Anatomía de la identidad

| Dimensión | Observación y alcance |
|---|---|
| Fondo y color | La captura publicada en 2025 presenta fondo negro, blanco tipográfico y acento de logotipo amarillo. Estudios externos 2026 también describen ese sistema; **no** usar un hex como si hubiera sido medido ahora. |
| Tipografía | Titulares tipográficos grandes y muy legibles, navegación discreta, proyectos como bloques protagonistas. La fuente exacta y el comportamiento responsive requerirían capturas verificadas; no instalar la tipografía comercial sin licencia. |
| Fotografía y recursos | El protagonismo visual corresponde a las propias identidades/obras diseñadas, con marcas, formas y campañas. No hay necesidad de añadir fotos de oficina de stock. |
| Primer viewport | El sitio identifica al estudio de inmediato y luego dirige a trabajos concretos; un vídeo/showreel es contenido disponible en la web oficial, pero no se ha medido autoplay ni peso. |
| Composición interior | Casos con clientes y problema de marca, páginas de servicios de estrategia, identidad, digital y campaña, y contacto para encargos. |
| Navegación/acción | La separación «Work / Services / About / Contact» respalda un recorrido empresa → caso → servicio → contacto. Lo esencial es tener obra real, no copiar su menú. |

**Lo que la hace diferente:** Cuando hay trabajos excelentes, la web puede hablar menos: deja que el proyecto demuestre qué sabes hacer.

### Qué adaptar en una empresa de servicios pequeña
Para diseñador o estudio pequeño: 3 casos propios con antes/después de identidad cuando haya permiso, cada uno con papel realizado, fecha y prueba; CTA «Cuéntanos tu proyecto».

### Boceto original para una pyme
Portada de alto contraste con un caso a pantalla completa, detalle del problema resuelto y lista estrecha de otros trabajos; no forzar grandes animaciones o vídeo si la empresa no tiene ese material.

**Ejemplo de copy humano (hipotético, revisar datos antes de publicar):** ««Esto resolvimos para [cliente autorizado]: [problema real] y [trabajo realizado]». Sin prometer porcentajes de conversión no medidos.»

**No copiar:** No utilizar marcas Apple/Microsoft/Amazon como clientes propios ni copiar material de Koto. No usar negro como paleta por defecto para todos los profesionales.

### Preguntas de QA y móvil
Probar filtros/trabajos, vídeo con poster y reduced motion si se agrega, textos accesibles, foco, tamaños de imagen y CTA visible.
