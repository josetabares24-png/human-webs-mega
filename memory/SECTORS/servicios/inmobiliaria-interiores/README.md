# Inmobiliaria, arquitectura e interiorismo

Agentes inmobiliarios, home staging, diseño de interiores, arquitectura, reforma integral.

**Funciones que importan:** Portafolio visual real, ubicación/área, alcance por proyecto, proceso y valoración/presupuesto.

**Riesgo de copiar sin contexto:** No inventar casas, renders como obra terminada, métricas, permisos ni resultados; no asumir que una agencia requiere un portal de anuncios.

## Referencias investigadas (pendientes de aprobación)

- **[The Modern House](the-modern-house.md)** — agencia inmobiliaria editorial. Para inmobiliarias, reformas o arquitectura: fotos reales de propiedades/proyectos, detalles útiles, proceso de trabajo, zona y CTA «Solicitar valoración» con contacto real.
- **[Havenly](havenly.md)** — servicio de interiorismo. En reformas/interiorismo, presentar alcance real por paquete, fotos antes/después autorizadas, cronograma sujeto a presupuesto y tareas del cliente frente al proveedor.

**Análisis ampliado:** cada caso incluye evidencia visual, lectura de tipografía/fondo/foto/CTA, propuesta original para una pyme y comprobaciones pendientes. [Comparativa de diez](../COMPARATIVA-VISUAL.md).

Las fichas derivan de páginas web públicas consultadas el 30/10/2026. **No hay capturas nuevas de móvil ni inspección de CSS**; las conclusiones visuales no medidas se marcan como interpretaciones.
