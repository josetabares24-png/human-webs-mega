# Webs de servicios — referencia sectorial

**Estado 30/10/2026:** 10 referencias reales clasificadas; todas son **investigación pendiente de valoración estética del usuario**, no ejemplos que el usuario haya aprobado. Se revisaron páginas web oficiales (contenido y funciones descritas) y algunas imágenes públicas disponibles; **no** se ejecutó una auditoría visual móvil con navegador ni se midieron colores o CSS.

## Cinco preguntas de entrada
1. **Qué problema concreto resuelves** (no «servicios de calidad»).
2. **Dónde trabajas** (oficina, área de cobertura, a domicilio, online).
3. **Qué incluye** cada servicio y qué no; precios si son reales o presupuesto bajo solicitud.
4. **Por qué confiar** (equipo, casos, permisos, reseñas verificadas con consentimiento, atención al cliente).
5. **Qué sucede al hacer clic:** ¿llamada, WhatsApp, formulario que llega a alguien, solicitud de cita, reserva confirmada, pago?

## Diferencia clave: empresa vs marketplace
Las referencias incluyen plataformas que agrupan cientos de profesionales (Checkatrade, Fixando, Zaask, Treatwell) y empresas que venden sus propios servicios. **No replicar motores de búsqueda, rankings o calendarios de plataformas** para una pyme si no existe la infraestructura.

## Dirección visual
No usar automáticamente azul sanitario, verde corporativo, blancos con tarjetas ni terracota. Derivar colores/tipografía de oficio, lugar, herramientas, equipo y marca real; comparar tres direcciones diferentes en contenido y composición, sin copiar las webs de referencia.

## Fotografía y credibilidad
Solo trabajos del prestador con autorización; no presentar imágenes de stock como proyectos realizados ni profesionales generados como empleados reales. Los nombres, títulos, colegiaciones, certificados y opiniones requieren evidencia.

## Estatus y próximos pasos
Los estudios registrados pueden ser **candidatos** de ideas. Cuando el usuario envíe captura que apruebe un detalle, documentar ese rasgo concreto; no convertir los diez sitios completos en plantilla.
