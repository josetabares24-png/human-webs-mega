# Hogar, mantenimiento y presupuestos

Limpieza, bricolaje, reformas, electricistas, fontanería, jardinería. Diferenciar una empresa prestadora de un marketplace.

**Funciones que importan:** Servicio preciso y límites; zona de cobertura; cuándo se puede atender; cómo se pide presupuesto; alcance y costes explicados; pruebas reales del trabajo.

**Riesgo de copiar sin contexto:** No montar una plataforma con 5 especialistas para un autónomo. No crear mapas con puntos inventados ni mostrar estimadores de precio sin regla real.

## Referencias investigadas (pendientes de aprobación)

- **[Housekeep](housekeep.md)** — servicio/operador y plataforma. Separar servicios que requieren diferentes presupuestos y mostrar tareas incluidas/excluidas; pedir zona antes de prometer disponibilidad.
- **[Checkatrade](checkatrade.md)** — marketplace de oficios. En un negocio de oficios, crear servicios claros («reparación de fuga», «instalación») y rutas rápidas a contacto, área de cobertura y ejemplos propios de trabajos.
- **[Fixando](fixando.md)** — marketplace portugués de servicios. Para servicios en Portugal, emplear términos locales de pt-PT, formularios breves que recojan lo imprescindible (tipo, zona, urgencia, contacto) y explicar el paso posterior.
- **[Zaask](zaask.md)** — marketplace portugués de servicios. Para proveedores pequeños, sección «Cómo trabajamos» de 3 pasos, categorías reales, áreas atendidas y CTA directo al presupuesto; copy natural de Portugal.

Las fichas derivan de páginas web públicas consultadas el 30/10/2026. **No hay capturas nuevas de móvil ni inspección de CSS**; las conclusiones visuales no medidas se marcan como interpretaciones.
