# Excursiones, visitas guiadas y experiencias

Operadores y plataformas de actividades: fotos reales, duración, precio y condiciones, guía, idioma, punto de encuentro, reserva o enlace.

**Principal riesgo:** No inventar plazas, reseñas, disponibilidad ni captación con calendarios falsos; distinguir plataforma de guía individual.

## Referencias documentadas (preferencia pendiente)

- **[GetYourGuide](getyourguide.md)** — marketplace de actividades y entradas. Eliminar dudas **antes** del botón de reserva: duración, precio, punto de encuentro, idioma, cancelación y qué incluye.
- **[GuruWalk](guruwalk.md)** — marketplace de free tours y guías. El catálogo tiene valor cuando la persona puede comparar **hora, recorrido, idioma y guía**, no cuando acumula fotos bonitas.
- **[Atlas Obscura](atlas-obscura.md)** — guía editorial de lugares singulares. El SEO de turismo mejora con historias concretas y **ubicaciones útiles**, no cambiando una lista de «10 imprescindibles» cada mes.

Las fichas fueron estudiadas el **31/10/2026** con fuentes originales y material visual atribuido donde existía. No se han generado capturas móviles recientes ni se ha inspeccionado CSS; no atribuir fuentes o paletas de un archivo histórico a la web actual.
