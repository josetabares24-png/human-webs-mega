# Destinos, ciudades y guías

Medios y oficinas turísticas: inspiración + mapas, logística, temporadas, itinerarios e información local.

**Principal riesgo:** No convertir guía editorial en portal de reservas sin producto real; no generar rutas/horarios falsos.

## Referencias documentadas (preferencia pendiente)

- **[Visit Iceland](visit-iceland.md)** — oficina turística oficial de país. Cuando el destino es amplio, el mapa puede **ser un producto útil**, no un widget añadido al final.
- **[Visit Faroe Islands](visit-faroe-islands.md)** — destino/islas con logística especial. Aventura emocional + **información difícil** de viajes (clima, ferris, riesgos) presentada sin fricción.
- **[Visit Copenhagen](visit-copenhagen.md)** — guía oficial de ciudad con itinerarios. Lo atractivo no se opone a lo útil: **horas reales, barrios cercanos, presupuesto y transporte** orientan al visitante.

Las fichas fueron estudiadas el **31/10/2026** con fuentes originales y material visual atribuido donde existía. No se han generado capturas móviles recientes ni se ha inspeccionado CSS; no atribuir fuentes o paletas de un archivo histórico a la web actual.
