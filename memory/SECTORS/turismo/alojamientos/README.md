# Hoteles, alojamientos y hospitalidad

Hoteles pequeños y cadenas: fotografías propias, habitaciones, barrio, ubicación, calendario y condiciones de estancia.

**Principal riesgo:** La fecha seleccionada no equivale a disponibilidad; no simular reservas confirmadas ni inventar habitaciones.

## Referencias documentadas (preferencia pendiente)

- **[The Hoxton](the-hoxton.md)** — cadena de hoteles urbanos de barrio. La estancia se vende con contexto local **y** datos de reserva claros, no únicamente con una foto bonita.
- **[Casa Cook](casa-cook.md)** — colección de resorts boutique. La fotografía del **espacio real** aporta personalidad: la calma puede ser única sin añadir transiciones lentas o marcos terracota.
- **[Sublime Hotels](sublime-hotels.md)** — grupo de hospitalidad y hoteles portugueses. Cuando hay varios negocios bajo una marca, un índice visual debe **orientar**, no mezclar 50 elementos indiscriminadamente.

Las fichas fueron estudiadas el **31/10/2026** con fuentes originales y material visual atribuido donde existía. No se han generado capturas móviles recientes ni se ha inspeccionado CSS; no atribuir fuentes o paletas de un archivo histórico a la web actual.
