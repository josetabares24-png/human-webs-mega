# Agencias, circuitos y viajes personalizados

Viajes de varios días, grupos y propuestas a medida: itinerario por día, inclusiones, condiciones, presupuesto y esfuerzo.

**Principal riesgo:** No copiar itinerarios de terceros, precios cambiantes, títulos de operador o sellos de sostenibilidad.

## Referencias documentadas (preferencia pendiente)

- **[Intrepid Travel](intrepid-travel.md)** — operador de viajes en grupo. Mostrar **nivel de esfuerzo** y condiciones desde la búsqueda evita que un buen diseño venda una ruta equivocada.
- **[G Adventures](g-adventures.md)** — operador de circuitos y viajes con itinerarios. Separar **confirmado / tentativo / opcional** es más útil que llenar una web de promesas.
- **[Black Tomato](black-tomato.md)** — operador de lujo con viajes hechos a medida. La dirección artística **promete una experiencia editorial**, mientras la conversión es hablar con una persona para diseñar el itinerario.
