# Estándar de ficha de turismo — sin fingir medidas

1. **Tipo y escala:** destino oficial, guía editorial, operador local, marketplace, agencia o hotel. No copiar una plataforma a un negocio pequeño.
2. **URL exacta, fecha y fuentes:** original + páginas internas; capturas de terceros fechadas por separado.
3. **Visual real:** fondo/color, tipografía, fotografía, primer viewport, estructura, navegación y CTA. Si no hay screenshot actual o CSS, etiquetar **no medido**.
4. **Producto de turismo:** qué necesita hacer el visitante (planificar, comparar, reservar, llegar).
5. **Un principio transferible**, no una plantilla completa; explicar por qué funciona para ese modelo.
6. **Boceto propio para pyme:** contenido auténtico y navegación proporcional a su tamaño.
7. **Copy específico** marcado como ejemplo hipotético, sin datos o promesas inventados.
8. **Riesgos:** licencia de medios, lugares, clima, horarios, tarifas, disponibilidad, reseñas, enlaces afiliados y condiciones.
9. **QA real:** fotos cargadas, móvil, mapa/lista accesibles, enlaces externos, motor de reserva probado, idiomas y datos actuales.
10. **Aprobación:** `PENDIENTE` hasta que el usuario señale en captura qué aprecia o rechaza.

## Método de esta primera edición
Se consultaron las webs originales con navegador textual y material visual público atribuido. No se realizaron capturas nuevas de 390 y 1280 píxeles ni inspección de CSS computado, por lo que se declara explícitamente lo no verificado. Las fotografías de referencia no son assets libres que se puedan usar en webs de clientes.
