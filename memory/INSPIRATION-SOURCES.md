# Directorios para investigar referencias reales (no son plantillas)

Verificados como puntos de descubrimiento el **30 de octubre de 2026**. Estos directorios **no demuestran** el aspecto actual de un sitio enlazado: abrir cada web original y registrar observaciones con fecha y viewport.

| Fuente | Cuándo sirve | Precaución |
|---|---|---|
| [Siteinspire](https://www.siteinspire.com/) | Filtrar por estilo, tipo, sector y tipografía; ver composiciones poco convencionales | Hay referencias de estudios con más presupuesto que un negocio local |
| [Minimal Gallery](https://minimal.gallery/) | Tipografía, espacio, editoriales, portfolios y negocios con estética contenida | «Minimal» no es sinónimo de copiar fondos crema y tarjetas blancas |
| [Curated Design](https://curated.design/) | Explorar sectores, estilos y secciones reales antes de buscar el sitio original | Algunas funciones de búsqueda avanzada son de pago; no asumir acceso |
| [Godly](https://godly.design/sites/) | Contraste visual: agencias, tecnología, e-commerce y referencias expresivas | No replicar animación pesada sin necesidad ni medición |

## Consultas útiles
- Negocio local: `[sector] independent studio website`, `[ciudad] [sector] design website`, `[sector] typographic editorial website`.
- Opciones contrastantes: `[sector] bold color website`, `[sector] minimal black white website`, `[sector] unconventional navigation`.
- Buscar **una referencia transferible de otro sector**: arquitectura (espacio), museo/editorial (lectura), comercio (producto), cultura/eventos (personalidad). Registrar qué se transfiere y qué se descarta.

## Proceso
1. Acotar objetivo y público antes de navegar; no buscar «las mejores webs» sin contexto.
2. Usar estas galerías **para descubrir** y luego abrir sitio oficial. Registrar URL, fecha y qué se observó realmente.
3. Inspeccionar al menos una pantalla móvil y una desktop si están disponibles; contrastar home y página interior.
4. Elegir patrones reutilizables **como principios originales** y documentar restricciones/licencias.
5. Crear **tres sistemas visuales** diferentes siguiendo [ART-DIRECTION](ART-DIRECTION.md). La paleta nunca es la única diferencia.
