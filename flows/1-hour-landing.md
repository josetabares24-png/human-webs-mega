# Flujo de 1 hora: Landing humana

Para cuando necesitas entregar rápido algo que no se sienta a IA.

## Minutos 0–10: Brief y mensaje

- Qué vende / ofrece.
- A quién.
- Principal beneficio o problema que resuelve.
- CTA deseado.
- Paleta o referencias visuales (opcional).

Escribe el titular y el subtítulo en lenguaje humano antes de tocar diseño.

## Minutos 10–30: Estructura y copy

1. Hero (titular + sub + CTA).
2. Problema (2–3 líneas concretas).
3. Solución / cómo funciona (3 puntos máx.).
4. Prueba (1–2 testimonios o hechos).
5. CTA final.

Usa el checklist de `principles/human-copy.md`.

## Minutos 30–50: Construcción

- Stack rápido: Astro + Tailwind, o HTML + CSS puro, o plantilla limpia.
- Aplica jerarquía visual fuerte.
- Una sola tipografía principal + una secundaria si hace falta.
- Espacio generoso.

## Minutos 50–60: Revisión y deploy

- Checklist anti-IA.
- Probar en móvil.
- Deploy (Vercel, Netlify, etc.).
- Entregar link + instrucciones mínimas.

Resultado: una landing que se entiende en 5 segundos, suena humana y está online.
